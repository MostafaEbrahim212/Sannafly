# Changelog

## [2.0.0] - 2026-11-27
### Added
- Complete White-Label system with neutral defaults and dynamic brand logo/favicon/social/footer settings.
- Separated `EssentialSeeder` (RBAC, settings, gateways) from optional `DemoCatalogSeeder`.
- Secure 7-step Web Installer (`/install`) with real server checks, DB connection test, `.env` backup/writer, and dual installation lock.
- Niche Theme Presets (Electronics, Fashion, Cosmetics, General Store, Minimal, Modern, Luxury) & Homepage Sections Reorderer in Customizer.
- Commercial Licensing & Update Architecture (`/admin/license`) with domain binding and 14-day offline grace period.
- SQL Backup Restore, Support Diagnostic Report export, and Customer GDPR Data Export / Anonymization.
- Real-Time Notifications Center (`/admin/notifications`, `/account/notifications`) and live feed sync.
- System Logs Viewer (`/admin/system-logs`) and System Tools (`/admin/system-tools`).
