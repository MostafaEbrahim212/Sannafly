# User Guide — Admin Dashboard

- **Dashboard (`/admin`):** Real-time sales KPIs, pending orders, low-stock alerts, and live notifications.
- **Products, Categories, Brands & Attributes:** Full catalog management with multi-currency/tier pricing (`Regular`, `Sale`, `Wholesale`), variations, and WebP image optimization.
- **Inventory (`/admin/inventory`):** Atomic stock adjustments with full movement audit history and low-stock notifications.
- **Orders (`/admin/orders`):** Status state machine (`pending` → `confirmed` → `processing` → `shipped` → `delivered`), tracking numbers, printable A4 invoices, and AWB shipping labels.
- **Shipping Zones (`/admin/shipping-zones`):** Governorate/city matching, flat + weight-based (`base_weight_kg`, `per_kg_rate`) rates, and free-shipping thresholds.
- **Coupons (`/admin/coupons`):** Percentage, fixed, free shipping, first-order-only, and per-customer usage limits.
- **Payment Methods (`/admin/payment-methods`):** Enable/disable and configure Fawry, MyFatoorah, Paymob, Kashier, InstaPay/Vodafone Cash (`wallet_transfer`), Bank Transfer, Cash, and COD.
- **Customizer (`/admin/customizer`):** White-label brand name, colors, light/dark presets, industry niche presets, homepage section ordering, promotional bar, and popup.
- **System Logs (`/admin/system-logs`):** View, filter, search, download, or clear structured application/payment/security/slow-query logs.
- **System Tools (`/admin/system-tools`):** Cache clearing, production optimization, SQL/ZIP backups & SQL restore, queue retry/flush, maintenance mode, and support diagnostic reports.
- **License & Updates (`/admin/license`):** Manage commercial license activation, domain binding, and version checks.
